# Administrator Subsystem Screen & Requirement Checklist (`docs/admin-screen-checklist.md`)

**Project:** Chat System — Course Final Project (Version 1: UI & Database Design)  
**Subsystem Owner:** Member 2 — Administrator Desktop Application (`chat-admin/`) & Shared PostgreSQL Database (`script/`)  
**Scope Notice:** Version 1 is a **Java Swing UI and Database Design deliverable**. The Swing UI operates on deterministic in-memory mock data (`MockUserRepository.java`) aligned 1:1 with the PostgreSQL seed data (`script/02_seed.sql`) and administrative SQL queries (`script/03_admin_queries.sql`). No live Spring Boot, TCP socket, or JDBC database connection is claimed or required in Version 1.

## 2. Shared UI & Architectural Audit Results

1. **Zero Placeholder Views Remaining:** All 9 navigation items in `SidebarPanel.java` route to completed, interactive Swing screens in `AdminMainFrame.java`.
2. **Populated, Empty-Result, and No-Selection States:**
   - Every table-based screen (`UserManagementPanel`, `LoginHistoryPanel`, `ChatGroupManagementPanel`, `SpamReportPanel`, `NewUserRegistrationPanel`, `FriendStatisticsPanel`, `UserActivityPanel`) supports populated default data, an explicit empty-result state when filters match 0 records, and an explicit no-selection state (`Bỏ chọn`).
   - Both chart screens (`RegistrationChartPanel`, `ActivityChartPanel`) support populated months, zero-count months (`0` badge on baseline), and an explicit **Empty-Year State** (`Năm 2024`).
3. **Input & Date-Range Validation:**
   - All date-range filters (`LoginHistoryPanel`, `SpamReportPanel`, `NewUserRegistrationPanel`, `UserActivityPanel`) validate `YYYY-MM-DD` format and enforce `From Date <= To Date` with an inline red validation banner.
   - Numeric filters (`FriendStatisticsPanel`, `UserActivityPanel`) validate non-negative integer inputs.
4. **No Machine-Specific Paths or External Runtime Assets:**
   - Verified zero hardcoded absolute paths and zero external network/file dependencies in `chat-admin/src/`; all icons, badges, avatars, and bar charts are rendered using pure `java.awt.Graphics2D`.
5. **Unobtrusive Version 1 Mock-Data Preview Label:**
   - `HeaderPanel.java` displays a subtle `"Version 1 • Mock Data Preview"` pill badge in the top header bar, and the window title is labeled `"ChatSystem Admin (Version 1 Mock Preview)"`.
